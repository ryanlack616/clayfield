# Privacy

ClayField is local-first.

- The desktop app processes images and generates models on your machine. It does
  not upload your images, projects, or exports.
- The planned web app is a static client-side application with no backend. Files
  are read from and written to your own device (File System Access API, OPFS,
  IndexedDB).
- **No telemetry, analytics, or tracking** by default.
- If opt-in crash reporting is ever added, it will be off by default, clearly
  disclosed, and redact project content. There is no such feature today.
- Clearing browser site data deletes locally stored projects and settings; export
  projects you want to keep.

If any of this changes, this file and the plan docs must be updated before the
change ships.
