# contracts/

The frozen contract artifacts. This directory is what C8a checks in and what the
CI drift check compares against.

| File | What it is |
|---|---|
| [`types.ts`](types.ts) | Authoritative TS types for README §4–§11. C1 compiles it. |
| [`abi-v1.md`](abi-v1.md) | Byte-level WASM ABI v1 wire layout. |
| [`version.json`](version.json) | The four version numbers and the frozen subset list. |
| `api-report.md` | Generated by `api-extractor` at C8a. Not hand-written. |

## Rules

1. **C1 compiles `types.ts`.** "Taxonomy types compile" means `tsc --noEmit`
   over this file exits 0. Until that passes, C1 is not done.
2. **C8a freezes the subset named in `version.json`.** Everything else stays
   mutable.
3. **After C8a, changes to the frozen subset are additive only** — new optional
   fields, new union members — plus a minor version bump and an ADR. Never
   rename or remove without a major bump.
4. **`api-report.md` is generated, never edited.** The CI drift check re-runs
   the generator and fails if the output differs from the committed file.
5. **No domain terms.** The forbidden-terms lint applies here too.

## Why this directory exists

The core plan names ~40 types across §4–§11. Without definitions those are
labels, and C1's exit criterion ("taxonomy types compile") has nothing to
compile. `types.ts` is that definition. It is deliberately structural: field
names and types, no implementation.
